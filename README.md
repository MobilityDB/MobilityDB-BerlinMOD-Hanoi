# BerlinMOD-Hanoi Data for MobilityDB

**This repository is archived. The base map of Hanoi is maintained in
[MobilityDB-BerlinMOD/BerlinMOD/hanoi](https://github.com/MobilityDB/MobilityDB-BerlinMOD/tree/master/BerlinMOD/hanoi),
beside the base map of Brussels, with its preparation script, the GeoJSON export, the steps that
generate the data and the generated datasets.**

**Authors.** The base map of Hanoi, its preparation script, the GeoJSON export, the figures and the
generated datasets are the work of [Ngoc Hoa Pham](https://github.com/ngochoawindy), first
published here; the history of this repository records it.
